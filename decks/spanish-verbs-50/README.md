# Spanish verbs: 51 common verbs in example sentences

Free deck, identical to the file on [ankiwordbank.com](https://ankiwordbank.com/decks/master-spanish-verbs-50-most-common-verbs-conjugation).
Each verb appears in an everyday sentence, conjugated where natural (*¿Puedes…?*, *Estoy…*).
It does not include conjugation tables.

- **File:** [`spanish-verbs-50.apkg`](spanish-verbs-50.apkg)
- **Every card:** [`words.tsv`](words.tsv)
- **Notes:** 52 in the file. Anki imports 51, because #1 (*poder*) and #41 (*ayudar*) use the same sentence and merge. *comer* appears twice (#13, #46).
- **Cards:** English sentence on the front; Spanish sentence with the verb in bold, plus audio, on the back.
- **Audio:** neural text-to-speech (synthetic voice). Every note has audio.

For a wider vocabulary, the [Spanish Top 1000 sample](../spanish-top-1000-first-100/) is free too.
